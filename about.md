# ABOUT THE PROJECT

## 📊 Sales Analytics Dashboard

This interactive Sales Analytics Dashboard is developed using Microsoft Excel to analyze sales performance across products, regions, months, and salespeople.

### 🎯 Project Objective
The main objective of this dashboard is to transform raw sales data into meaningful insights that help understand business performance and support data-driven decision-making.

### 📈 Key Insights

- **Total Sales Amount:** ₹17,82,570
- **Total Sales:** 366
- **Total Quantity Sold:** 1,607
- **Top-Selling Product:** Printer
- **Highest Sales Region:** East
- **Top-Performing Salesperson:** Siddhu

### 🔍 What This Dashboard Analyzes
- Monthly sales trends
- Region-wise sales performance
- Product-wise sales contribution
- Top 3 and bottom 3 products
- Top 3 and bottom 3 salespeople
- Interactive analysis using date, region, and product filters

### 🛠️ Tools Used
Microsoft Excel, Pivot Tables, Pivot Charts, Timeline, and Interactive Filters.

### 💡 Business Value
This dashboard helps identify high-performing products, compare regional sales, evaluate salesperson performance, and discover opportunities for business improvement.

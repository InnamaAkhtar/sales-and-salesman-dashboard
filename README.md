


# 📊 Sales Analytics Dashboard

## 📌 Project Overview

An interactive Sales Analytics Dashboard developed using Microsoft Excel
to analyze sales performance across products, regions, months, and salespeople.

The dashboard converts raw sales data into meaningful business insights
using interactive filters, KPI cards, and visualizations.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track total sales amount and quantity.
- Identify top-selling and least-selling products.
- Compare sales across different regions.
- Analyze monthly sales trends.
- Evaluate salesperson performance.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers and Timeline Filters
- Data Analysis
- Data Visualization

## ✨ Dashboard Features

### 1. Sales Dashboard
- Total Amount
- Total Sales
- Total Quantity
- Monthly Sales Analysis
- Region-Wise Sales
- Product-Wise Sales Contribution

### 2. Product Analysis
- Product-Wise Sales Comparison
- Top 3 Best-Selling Products
- Top 3 Least-Selling Products

### 3. Salesperson Analysis
- Salesperson-Wise Sales Performance
- Top 3 Performing Salespeople
- Bottom 3 Performing Salespeople

### 4. Interactive Filters
- Date Timeline
- Region Filter
- Product Filter

## 💡 Business Value

This dashboard helps businesses monitor sales performance, identify
high-performing products, compare regional results, and evaluate
salesperson productivity.
